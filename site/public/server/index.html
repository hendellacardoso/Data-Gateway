Perguntas frequentes

Dúvidas comuns

Em quais sistemas o Server Manager funciona?

Em Windows Server. Ele é instalado como Serviço do Windows e o painel é acessado pelo navegador, de qualquer computador autorizado.

Preciso mudar as aplicações que já estão no servidor?

Não. Você pode cadastrar aplicações existentes, monitorar serviços externos por HTTP/TCP e usar o Caddy que já estiver instalado (modo externo), sem mexer no que funciona.

O que acontece com as aplicações quando o Server Manager é atualizado?

Elas continuam rodando. A atualização é oferecida no painel, só é instalada com a aprovação do administrador e o instalador é verificado (SHA-256) antes de rodar. Os dados e configurações são preservados.

É seguro expor o painel na internet?

O painel tem 2FA, perfis de acesso, restrição por redes autorizadas e auditoria. A Central de Segurança indica o que ajustar. Também é possível manter o painel acessível só pela rede interna ou VPN.

Funciona com sistemas feitos no Maker?

Sim: Maker Studio, Maker 5 e Maker AI, cada um com seu ambiente Webrun isolado, Tomcat e Java compatíveis.

Consigo gerenciar mais de um servidor?

Sim. Um Server Manager central pode gerenciar outros servidores com tokens de acesso, sempre com as permissões do usuário logado e registro na auditoria.
