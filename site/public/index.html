Como funciona

Do banco à API publicada em 4 passos

O Data Gateway fica entre os seus aplicativos e o banco de dados. Quem consome a API nunca acessa o banco diretamente: só enxerga as tabelas, campos e operações que você liberou.

Segurança

Seu banco continua fechado. A API só faz o que você liberou.

O Data Gateway não executa SQL enviado por quem chama a API. Tabelas, campos, filtros e ordenações vêm de uma lista autorizada e todo valor recebido vira parâmetro.

Baixar agora
  • Whitelist de tabelas, campos, operadores e ordenações
  • Consultas 100% parametrizadas (sem SQL injection)
  • Token apenas no cabeçalho Authorization: Bearer
  • Rate limit por token e timeout de consultas
  • Senhas do painel com scrypt; tokens guardados como SHA-256
  • Senhas do banco protegidas pelo Windows (DPAPI)
  • Consultas SQL publicadas em modo somente leitura
  • Erros sem stack trace nem mensagens internas do banco

Primeiros passos

Como usar

  1. Instale ou abra o portátil. No primeiro acesso, crie o usuário administrador do painel.
  2. Conexões → Bancos → Novo. Escolha o tipo do banco, informe servidor, porta, banco, usuário e senha e clique em Testar. Para consultas e relatórios, prefira um usuário de banco só com leitura.
  3. APIs → Endpoints → Nova API. O assistente mostra as tabelas. Escolha a tabela, o endereço (ex.: clientes), os campos, quais filtros e ordenações são permitidos, a paginação e as operações (consultar, incluir, alterar, excluir).
  4. APIs → Tokens. Gere um token para cada sistema que vai consumir a API e marque as permissões. Copie o token: ele é exibido uma única vez.
  5. Teste. Use o Testador de API ou abra a Documentação (Swagger). A API responde em http://SEU-PC:8787/api/v1/… (porta configurável em Sistema → Configurações).
  6. Publique na rede ou na internet. Libere a porta no firewall para uso na rede local, ou coloque um proxy com HTTPS (Caddy, Nginx, IIS) na frente para acesso externo.
# Clientes de Goiânia, 20 por página, ordenados pelo nome
curl -G "http://localhost:8787/api/v1/clientes" \
  --data-urlencode "cidade=Goiânia" -d sort=nome -d pageSize=20 \
  -H "Authorization: Bearer SEU_TOKEN"

# Inclui um cliente
curl -X POST "http://localhost:8787/api/v1/clientes" \
  -H "Authorization: Bearer SEU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"nome":"Maria Silva","cidade":"Goiânia"}'
const resp = await fetch('http://localhost:8787/api/v1/pedidos/1520?expand=itens', {
  headers: { Authorization: 'Bearer ' + token }
});
const { success, data, error } = await resp.json();

if (!success) console.error(error.code, error.message);
else console.log(data.cliente, data.itens.length);

Dúvidas frequentes

Perguntas e respostas

É gratuito mesmo?

Sim. O Data Gateway pode ser baixado e usado gratuitamente, inclusive em empresas. Não há limite de endpoints, tokens ou requisições.

Preciso saber programar?

Não para publicar a API: tudo é feito em telas. Para consumir a API você usa a ferramenta de sua preferência (app, site, Power BI, n8n etc.). Conhecer SQL ajuda apenas no recurso opcional de Consultas SQL.

Meus dados passam por algum servidor da API2Dev?

Não. O Data Gateway roda no seu computador ou servidor e conversa diretamente com o seu banco. Configurações ficam em um banco SQLite local, em %APPDATA%\Data Gateway.

Quais bancos são suportados?

Microsoft SQL Server, PostgreSQL, MySQL, MariaDB, Firebird (2.5 a 5.0) e SQLite. É possível ter várias conexões ao mesmo tempo, inclusive de tipos diferentes.

Funciona com o Firebird do meu sistema Delphi?

Sim, a partir da versão 1.2. Firebird 2.5, 3.0, 4.0 e 5.0, dialeto 1 e 3, inclusive bancos com charset NONE/WIN1252. Basta informar o servidor, a porta (3050) e o caminho do arquivo .FDB como o servidor enxerga. Não precisa instalar o fbclient.dll no computador do Data Gateway.

Posso alterar a estrutura do meu banco com ele?

Não. O Data Gateway não cria nem altera tabelas no seu banco. Ele só lê a estrutura e executa as operações de dados que você liberar em cada endpoint.

Como acesso a API de fora da minha rede?

Coloque um proxy reverso com HTTPS (Caddy, Nginx ou IIS) apontando para a porta do Data Gateway (padrão 8787) e use um domínio. Não exponha a porta do banco de dados.

Ele precisa ficar aberto?

Ele fica na bandeja do Windows e pode iniciar junto com o sistema. Com a opção de minimizar para a bandeja ativa, fechar a janela não derruba a API; para encerrar, use Sair no ícone da bandeja.

Como atualizo para uma versão nova?

Baixe o novo instalador e execute por cima — as configurações são mantidas. No portátil, basta substituir o executável. Recomenda-se exportar um backup antes (Sistema → Configurações).
